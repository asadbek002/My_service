# Do'kon uchun ikonkalar

- `app-store-1024.png` — App Store (1024×1024, shaffofliksiz, burchaklarni Apple o'zi yumaloqlaydi).
- `play-store-512.png` — Google Play (512×512, to'liq kvadrat; niqobni Android o'zi qo'yadi).
